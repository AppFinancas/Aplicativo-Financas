🔵 Versão 0.1 – MVP (Requisitos técnicos)

Escopo: Mínimo viável + Open Finance

📲 Frontend

  • [ ] Tela de login/cadastro com e-mail + senha
  • [ ] Tela de onboarding simples (explicar Open Finance)
  • [ ] Webview ou SDK para conexão Open Finance
  • [ ] Tela de dashboard com: Saldo total consolidado, Últimas transações, Gráfico de gastos por categoria (básico)
  • [ ] Tela de listagem de transações
  • [ ] Componente de categorização automática

🖥️ Backend

  • [ ] API de autenticação (JWT)
  • [ ] CRUD de usuários
  • [ ] Integração com Open Finance (via parceiro)
  • [ ] Webhooks para receber dados bancários
  • [ ] Serviço de categorização automática (regras fixas)
  • [ ] Banco de dados: User, Account, Transaction, Category

🔐 Segurança

  • [ ] Criptografia em repouso (dados sensíveis)
  • [ ] Token rotativo
  • [ ] Política de senha forte

🟡 Versão 0.5 – Evolução (Requisitos técnicos)

Escopo: Retenção e usabilidade

  • [ ] Login Google/Apple (OAuth2)
  • [ ] Tela de perfil editável
  • [ ] Serviço de notificações push (FCM)
  • [ ] Módulo de metas financeiras: Criar meta (nome, valor, prazo), Progresso visual, Sugestão mensal para atingir
  • [ ] Conteúdo educacional estático (sugestão de investimentos)
  • [ ] Melhoria na UI com Design System leve
  • [ ] Analytics de eventos (Firebase)

🟠 Versão 0.7 – Controle Avançado (Requisitos técnicos)

Escopo: Múltiplos perfis + cartões de crédito

  • [ ] Modelo de múltiplos perfis (Profile/Workspace) – Relação 1:N (usuário → perfis), Troca de contexto no app
  • [ ] Integração completa com dados de cartão de crédito via Open Finance: Limite, Fatura aberta, Faturas anteriores, Gastos por categoria no crédito
  • [ ] Extrato consolidado (conta + crédito)
  • [ ] Simulador "guarde mais": Quanto guardar por mês para meta X, Projeção de rendimento (cenários)
  • [ ] Indicadores financeiros (ex: comprometimento de renda)

🟢 Versão 1.0 – Maduro (Requisitos técnicos)

Escopo: Execução financeira + IA

  • [ ] Integração com APIs de corretoras/investimentos: Ordem de compra/resgate, Extrato de investimentos
  • [ ] Motor de recomendação baseado em regras + IA – Machine learning simples (TensorFlow Lite ou API)
  • [ ] Modo offline: Cache de transações, Sincronização ao voltar online
  • [ ] Exportador de relatórios (PDF, CSV)
  • [ ] Acessibilidade: TalkBack + VoiceOver
  • [ ] Internacionalização (PT-BR + EN)
  • [ ] Testes A/B configurável
